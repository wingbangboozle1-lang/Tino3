Disclosure — earlier repository history (R-13)

Seven earlier sessions published versions of this analysis. Some of those versions, and the commits that contain them, include the owner's ZIP codes and unrounded assessment figures. This edition removes those files from the served tree and republishes nothing of that kind, but Git history is not rewritten: the data remains reachable to anyone who inspects older commits, and any copy already crawled cannot be recovered. No destructive history rewrite was attempted because it would invalidate every other session's work and every fork.

What this edition does instead: the published artifact is an allowlist of ten pages plus assets; every other HTML or data path is replaced with a content-free withdrawal notice; the build fails if a ZIP-code pattern, a parcel number or a non-rounded amount appears in a published page.

How a value earns a place on this site

  1. Law or official rate — retrieved from the agency's own page during this session, quoted in the source library, linked from the row that uses it.
  2. Owner-provided input — labelled as such, rounded to $10, and never presented as verified.
  3. Scenario assumption — listed in the assumption register with its basis, and marked scenario in the table.
  4. Anything else — the cell stays empty and is listed above.
