What this section checks

Static pages generated from the JSON ledgers by integration/tools/build.py; integration/tools/verify.py checks reproducibility, structure, internal links, official-host citations, privacy patterns and $10 rounding.

The PR link, merge result and deploy confirmation are recorded in COORDINATION.md. The publication path is described by GitHub Docs · Configuring a publishing source for GitHub Pages and the integration method by GitHub Docs · Pull requests.

Privacy. Placeholders only; no name, street address, postal code, parcel number, city or neighborhood tied to a parcel, utility account number or unrounded roll figure. Every published dollar amount is a multiple of $10.
