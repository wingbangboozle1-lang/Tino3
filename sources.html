Method

  • Reproducible build. python scripts/model.py writes every figure; python scripts/build.py renders the pages; python scripts/verify.py fails the build if a page drifts from the model, if a link breaks, if an uncited table row appears, or if a rounded amount is not a multiple of $10.
  • Rounding. All dollar amounts are stored and displayed in $10 increments. Percentages and years are exact. Where an official figure is not a multiple of $10 it is shown rounded and the exact figure is quoted in the ledger row.
  • Privacy. Privacy boundary. No names, street addresses, ZIP codes, parcel numbers or unrounded assessment figures are published. Properties appear as [PROPERTY_A] and [PROPERTY_B]. All amounts are rounded to the nearest $10.
  • Limits. This is a planning model, not an appraisal, a title report, a tax return or legal advice. County-level property facts, insurance quotes and future law are outside what any public source can verify today.
