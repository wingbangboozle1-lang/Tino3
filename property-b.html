If Property B passes in the same estate

The owner states (11 November 2026) that the building is already owned by the beneficiary; the deed was not seen, so the question stays flagged (FL-01). If instead the parents hold title, the building changes ownership at the same death and is reassessed. In a multi-unit building the family-home exclusion covers only the unit that was the parent's principal residence and becomes the child's. Under the owner's statement none of this applies; the table is kept as the contingency case.

Which rent cap actually binds

Every projection on this site grows Property B's sitting-tenant rent at 1.5% a year, the local formula. That is right only if the local ordinance covers the building, and coverage was not looked up (FL-14, FL-32). If it does not cover it, the statewide cap in Civil Code 1947.12 applies instead: 5% plus the change in the cost of living, or 10%, whichever is lower — 7.5% a year at the modelled 2.5% inflation. Section 1947.12(d)(3) is what makes the two mutually exclusive: the state cap does not apply where a local ordinance already restricts increases to less than the state formula. The local cap is stricter, so where it applies it governs; where it does not, the state cap is five times looser. Section 1947.12(d)(4) is a second route to the same question: housing with a certificate of occupancy issued within the previous 15 years is outside the state cap altogether.
