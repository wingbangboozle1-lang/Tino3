Published, on purpose

The financial figures you supplied — two market values, both roll histories, both tax bills, the rent roll, the utility ranges and the insurance estimates — are published. They are what makes the analysis checkable, and without them the site would be the empty framework it should not be. They are also published with the identifiers stripped, and every one of them is labelled UNVERIFIED because none came from a public record.

If you would rather the figures were not public either, that is a single-point change: the model reads its inputs from scripts/model.py, and the pages can be regenerated with the amounts suppressed while keeping every rule and every projection method.

One honest caveat about history

This repository was built by several automated sessions before this one. Earlier versions of the site were published from the repository root at various points, and Git history is public. Those earlier versions did not contain names, addresses or parcel numbers, but some did contain the two ZIP codes and property figures. Removing a file from the latest commit does not remove it from history, and this project has not rewritten history. If complete removal matters, that is a separate, deliberate operation on the repository itself.
