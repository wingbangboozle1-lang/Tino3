Suggestions for review

A review queue of proposals, with a decision and date column for each one.

Nothing on the first list has been acted on

Every item in the first table is proposed. Building this site did not adopt, purchase, sign, file or change anything: it cannot obtain a quote, read a roll, or move title. The point of the page is that someone reads the list, chooses the best path, and only then acts. The selection gate below is the order in which to do that.

The second table is different in kind. It lists improvements to the site itself, and records which of them have already been built into this edition, so that a reader can tell an open question about the household's decision apart from a finished piece of analysis. A built item is not a decision made for the household; the household's own decisions are still blank.

One suggestion that is not optional

S-18 is the one item on the list that cannot be deferred, because it is the one that keeps the site honest. Every figure you see is generated from the data files in assets/data by scripts/model.py and scripts/build.py. If a number is edited directly in an HTML file, the next rebuild will overwrite it and the verification will still pass, because the verification checks the generated output, not the intent. Change the data, not the page.

How the numbers on this page are produced

Every computed figure on this page comes from scripts/model.py, which reads assets/data/inputs.json and assets/data/series.json. Monetary results are rounded to the nearest $10 before they are printed. The rules the model implements are the published official rules below; where a page uses a stated assumption or an unverified owner figure, that row says so and is logged on the register of unverified and assumed items.

  • California Legislative Information - Revenue and Taxation Code section 63.2
  • California State Board of Equalization - Publication 29, Property Taxpayers' Guide
  • Internal Revenue Service - Gifts and inheritances - inherited property basis and sale
  • Internal Revenue Service - Topic no. 409, Capital gains and losses
