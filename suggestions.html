How to use this page

  1. Read the register. Mark each row Adopt, Reject, or Defer outside the site; the site stores nothing.
  2. Priority A rows (SG-01, SG-02, SG-03, SG-06, SG-07, SG-14) decide how much of the analysis is evidence rather than assumption. Adopting one supplies a document and closes the matching flag.
  3. Choose a path. P1 is the recommendation on the numbers; P2, P3 and P4 stay open, and each names the evidence that would move it ahead.
  4. Implement only after the choice is recorded. A change means editing the model, re-running it, passing the three checks and republishing; no figure on the site is typed by hand.
  5. If a later fact differs from the register (a quote, the deed, a law change), record it, re-run, and compare the new result with the old one before publishing.
