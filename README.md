# Home Inheritance Decision Desk

A privacy-first, source-linked dashboard to organize a future Cupertino inheritance decision alongside a San Francisco rental property. The site separates current official rules from user-supplied, unverified estimates and identifies what needs to be verified before a live/rent/sell decision.

## Preview locally

Open `index.html` directly or serve the repository root with any static HTTP server.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` validates in-page anchors and deploys on pushes to `main` once GitHub Pages is configured to use GitHub Actions. GitHub Pages needs repository-level activation and a successful GitHub Actions deployment; this branch cannot itself prove deployment to a live URL.

## Privacy and limitations

No personal names, street addresses, parcel numbers, or account details are published. User-provided property and utility estimates are labeled unverified. Blank values are intentionally left blank. Legal, tax, insurance and investment information is general planning research, not professional advice. Recheck laws and all values near the actual transfer.
