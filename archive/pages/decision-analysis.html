Break-even: rent Property A vs. sell & reinvest

—

Break-even reinvest return = the return at which 10-year reinvested proceeds equal 10-year rental wealth (equity + cumulative net rent). If your expected after-tax return exceeds it, selling wins on pure wealth; if below, renting wins. Live-in is a lifestyle choice — compare its imputed rent saving to the sell path.
