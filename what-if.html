What-if controls

Change one assumption at a time and see how the four paths compare.

How the controls work

Each control is a set of links. Click a value and the page shows the case with that one assumption changed and the others kept. The page works without scripts: the browser shows the case named in the address.

Every case is a full run of the same model as the decision page. Nothing is estimated on the page itself. The baseline case is shown first.
